# backend-noma

API do Noma CRM. Node.js + Express + TypeScript + MongoDB Atlas (Mongoose).

## Rodar

```bash
cp .env.example .env
npm install
npm run dev
```

API em [http://localhost:3333](http://localhost:3333).

- `GET /api/health`
- `GET /api/contacts`
- `GET /api/companies`
- `GET /api/products`
- `GET /api/funnels`
- `GET /api/deals`
- `GET /api/users`
- `GET /api/transactions`
- `GET /api/tasks`
- `GET /api/nps`
- `GET /api/forms`
- `GET /api/labels`
